# Dataset description (pilot)

Own Assamese speech recordings for evaluating ASR before and after fine-tuning.

**Status:** pilot. 35 clips collected, 13 organised so far. Audio files are **not** published
in this repository (private individuals, including minors; consent for public release is being confirmed).

## Design
- Speakers from different regions of Assam (lower, central, upper, north, south) and age groups
  (child, teen, adult, old).
- Read and extempore speech.
- Used as a **held-out test set**. No speaker here is used for training.
- Collected remotely: friends and acquaintances recorded on their own phones.


## Known limitations
- Very small. With so few speakers, age, gender and region are mixed together, so results
  cannot be generalised from a single speaker.
- Remote collection means variable microphones and rooms.
